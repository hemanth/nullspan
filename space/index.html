In Plain English · What does nullspan actually do?

Think of it as a Smart Highlighter + Calculator — Not a Chatbot

When you ask a standard LLM (like GPT or Claude) to pull structured data out of messy text, it writes JSON word-by-word—which is slow, costs money per output token, can get tricked by "ignore previous instructions" attacks, and often makes up fake answers (hallucinates) when a field is missing. nullspan reads your text once and extracts every field in a single pass without generating a single word:

1. Points to Exact Text ([start, end] Span)

Instead of re-typing words, it highlights the exact character positions in your original text. Because it can only point to text that actually exists, it cannot hallucinate fake text or obey prompt injections.

2. Knows When to Say "Not There" (p_null)

If an answer isn't in the text (like an unassigned CVE or missing discount), it calculates the probability that the field is missing (p_null) and cleanly returns null instead of guessing.

3. Checks the Math Automatically (verified)

For numbers, dates, and invoices, it adds up line items, counts days between dates, and checks formulas like subtotal == nodes * hourly_rate so you know if the document's math is right.

4. Gives Realistic Ranges (p10 / median / p90)

When you ask for an estimate or forecast (like tomorrow's server traffic or repair cost), instead of one shaky guess, it returns a low (p10), middle (median), and high (p90) range.
